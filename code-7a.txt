# Experiment 7 — Secure Docker Image Publishing using Jenkins

## Aim

To create a secure Jenkins pipeline that **builds a Docker image, logs into Docker Hub using stored credentials, tags the image, and pushes it to a Docker registry**.

---

## Requirements

* Jenkins
* Docker Desktop
* Git/GitHub
* Docker Hub account
* A Dockerfile
* Jenkins **Username with Password** credential

---

# Procedure

## Step 1: Create Docker Hub repository

Create a free account on Docker Hub.

Create a repository, for example:

```text
jenkins-demo
```

Suppose your Docker Hub username is:

```text
yourusername
```

Your image will eventually be:

```text
yourusername/jenkins-demo:latest
```

---

# Step 2: Create a simple Docker project

Create:

```text
jenkins-docker-push/
│
├── app.txt
├── Dockerfile
└── Jenkinsfile
```

### `app.txt`

```text
Hello from Docker Hub!
```

### `Dockerfile`

```dockerfile
FROM alpine
COPY app.txt /app.txt
CMD ["cat", "/app.txt"]
```

---

# Step 3: Add Docker Hub credentials to Jenkins

In Jenkins:

**Manage Jenkins → Credentials → Global → Add Credentials**

Select:

```text
Kind: Username with password
```

Enter:

```text
Username: your Docker Hub username
Password: your Docker Hub password
ID: dockerhub-creds
```

The important part is:

```text
ID = dockerhub-creds
```

Jenkins will securely store these credentials.

**Do not write your Docker Hub password inside the Jenkinsfile.**

---

# Step 4: Create Jenkinsfile

Create:

```text
Jenkinsfile
```

Use:

```groovy
pipeline {
    agent any

    stages {

        stage('Build Image') {
            steps {
                bat 'docker build -t myapp .'
            }
        }

        stage('Login to Docker Hub') {
            steps {
                withCredentials([usernamePassword(
                    credentialsId: 'dockerhub-creds',
                    usernameVariable: 'DOCKER_USER',
                    passwordVariable: 'DOCKER_PASS'
                )]) {
                    bat 'echo %DOCKER_PASS% | docker login -u %DOCKER_USER% --password-stdin'
                }
            }
        }

        stage('Tag Image') {
            steps {
                bat 'docker tag myapp %DOCKER_USER%/jenkins-demo:latest'
            }
        }

        stage('Push Image') {
            steps {
                bat 'docker push %DOCKER_USER%/jenkins-demo:latest'
            }
        }
    }
}
```

### What is happening?

```text
Build
  ↓
Login securely
  ↓
Tag
  ↓
Push
  ↓
Docker Hub
```

The important security part is:

```groovy
withCredentials(...)
```

It allows Jenkins to use the username/password **without hardcoding them in the Jenkinsfile**.

# Result

**Thus, a secure Jenkins pipeline was successfully created to build a Docker image, securely authenticate with Docker Hub using Jenkins credentials, tag the image, and push it to the Docker registry.**


Main commands:

```text
docker build
docker login
docker tag
docker push
```

And the **security keyword** is:

```text
withCredentials
```

### One important point

You **do not manually type your Docker Hub password in the Jenkinsfile**. You enter it **once in Jenkins Credentials**, give it the ID `dockerhub-creds`, and Jenkins uses it through `withCredentials`.
